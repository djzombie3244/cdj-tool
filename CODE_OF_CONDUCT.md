# Code of conduct / Zasady współpracy

Be kind and respectful. Disagree with ideas, not with people. No harassment, discrimination, personal attacks or
publishing other people's private information. Keep issues and pull requests on topic and constructive.
*Bądź uprzejmy i szanuj innych. Spieraj się o pomysły, nie o ludzi. Bez nękania, dyskryminacji, ataków osobistych
i ujawniania cudzych danych prywatnych.*

Do not attach copyrighted music or firmware files to issues. / Nie dołączaj do zgłoszeń muzyki chronionej prawem
autorskim ani plików firmware'u.

Maintainers may edit, hide or remove comments and block people who break these rules. To report a problem, use
*Report content* on GitHub or open a private security report (see `SECURITY.md`).
*Opiekun może edytować, ukrywać lub usuwać komentarze oraz blokować osoby łamiące zasady.*
