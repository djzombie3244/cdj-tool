# Contributing / Współtworzenie

**EN.** Bug reports and pull requests are welcome. The most valuable thing you can do is to test on
real players and report results: player model and firmware, what loaded, what showed an error code
(for example `E-8709`). Please do not attach copyrighted music; a short synthetic test file is enough.

- Run the tests: `pip install -r requirements-dev.txt && python -m pytest`
- Keep the code free of personal paths and credentials.
- Changes to the database or ANLZ writers should be verified against a real export from rekordbox and, ideally, on a CDJ.

**PL.** Zgłoszenia błędów i pull requesty są mile widziane. Najcenniejsze jest testowanie na prawdziwych
odtwarzaczach: model i firmware, co się wczytało, co pokazało kod błędu (np. `E-8709`). Nie dołączaj
muzyki chronionej prawem autorskim, wystarczy krótki plik syntetyczny.
