# Security policy / Polityka bezpieczeństwa

**Supported version / Wspierana wersja:** the latest release. / Najnowsze wydanie.

**Reporting a vulnerability / Zgłaszanie podatności.** Please do not open a public issue. Use *Security → Report a
vulnerability* on the repository page (GitHub private reporting). Describe what you found and how to reproduce it.
Nie zakładaj publicznego zgłoszenia; użyj *Security → Report a vulnerability* na stronie repozytorium.

**Scope / Zakres.** CDJ Tool works offline. Its backend listens only on `127.0.0.1` and requires a random token for
every request; it reads the folders you choose and writes to the USB stick you choose. Reports about path handling,
the local HTTP backend, or damaged files crashing the analysis are especially welcome.

This is a hobby project: I answer as soon as I can, usually within a week. / To projekt hobbystyczny: odpowiadam
najszybciej jak mogę, zwykle w ciągu tygodnia.
