CDJ Tool for Windows (64-bit, Windows 10 or newer)
==================================================
1. Unzip this archive (right-click > Extract All).
2. Double-click Install.bat. No administrator rights are needed.
3. Start "CDJ Tool" from the Desktop or the Start menu. It opens in its own window (Edge or Chrome app mode).

Requirements: Windows 10/11 64-bit, Microsoft Edge (preinstalled) or Chrome. Works fully offline.
USB stick: FAT32 / MBR, up to 32 GB can be formatted from inside the app (Windows asks for permission).
To remove: run Uninstall.bat.

Polski: rozpakuj archiwum, uruchom Install.bat, potem skrót "CDJ Tool" na pulpicie. Bez internetu, bez praw administratora.
